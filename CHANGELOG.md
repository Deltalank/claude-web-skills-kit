# Changelog

All notable changes to this project will be documented in this file.

This project uses semantic versioning for public behavior of skills.

## [0.1.2] - 2026-06-20

### Added

- Added `security-web-audit` skill.
- Added security baseline, headers/CSP, privacy/cookies, output contract and severity references.
- Added security examples and activation tests.
- Updated README to include the implemented security skill.

### Notes

`security-web-audit` is experimental and focused on static website security, privacy, hosting configuration, headers, CSP, forms, cookies and delivery risks. It is not a penetration test or legal compliance certificate.

## [0.1.1] - 2026-06-20

### Added

- Added `web-premium-design` skill.
- Added premium design references, examples and activation tests.
- Updated README to list implemented and planned skills separately.

### Notes

`web-premium-design` is experimental and focused on visual direction, UX structure, anti-generic design checks and conversion-aware website design.

## [0.1.0] - 2026-06-20

### Added

- Initial repository structure.
- Initial `README.md`.
- Repository governance files: `AGENTS.md` and `CLAUDE.md`.
- First planned skill: `web-project-architect`.
- Validation and packaging scripts.

### Notes

This is an experimental professional draft. It is not yet a stable release.
