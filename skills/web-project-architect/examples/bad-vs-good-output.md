# Bad vs Good Output

## Bad output

```text
Te haré una web espectacular con 4.9 estrellas, testimonios de clientes felices, SEO garantizado y una conversión asegurada.
```

Why this is bad:

- invents ratings
- invents testimonials
- guarantees SEO
- guarantees conversion
- skips project discovery
- does not mark missing data

## Good output

```text
Puedo estructurar una landing profesional, pero necesito marcar datos pendientes antes de tratarla como lista para cliente.

Confirmed:
- Business type: gym
- Goal: WhatsApp contact

Missing / To confirm:
- opening hours
- legal business name
- real reviews
- photos
- pricing

Next action:
Create a project plan and content structure using placeholders where data is missing.
```

Why this is good:

- separates confirmed data from missing data
- avoids false claims
- moves the project forward safely
- creates a realistic next step
