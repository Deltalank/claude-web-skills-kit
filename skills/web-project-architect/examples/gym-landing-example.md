# Gym Landing Example

## User request

```text
Quiero crear una landing para un gimnasio local en Adeje. El objetivo es que contacten por WhatsApp.
```

## Expected skill behavior

The skill should not write code immediately. It should create a professional project plan.

## Expected output outline

- Project summary
- Confirmed information
- Inferred information
- Missing data
- Main website goal
- Target audience
- Recommended structure
- Required pages/files
- Design direction brief
- SEO/local SEO requirements
- Security and privacy requirements
- Accessibility and performance requirements
- Risks
- Quality gates
- Next action

## Safety notes

Do not invent:

- reviews
- ratings
- prices
- trainers
- owner name
- legal data
- opening hours
- guaranteed results
