# Workflow

`web-project-architect` follows this sequence:

1. Identify the request type.
2. Confirm whether the project is a real client project or a demo.
3. Separate confirmed, inferred and missing information.
4. Define the main website goal.
5. Define the target audience.
6. Propose website architecture.
7. Identify required pages and files.
8. Flag SEO, security, privacy, legal, accessibility and performance requirements.
9. Produce quality gates.
10. Recommend the next workflow or specialist skill.

## Do not skip planning

The skill should not jump directly into code unless the user explicitly asks for implementation and enough project context is available.
