# Output Contract

Default output format:

```md
# Website Project Plan

## 1. Project summary

## 2. Confirmed

## 3. Inferred

## 4. Missing / To confirm

## 5. Main website goal

## 6. Target audience

## 7. Recommended structure

## 8. Required pages/files

## 9. Design direction brief

## 10. SEO/local SEO requirements

## 11. Security and privacy requirements

## 12. Accessibility and performance requirements

## 13. Risks

## 14. Quality gates

## 15. Next action
```

The skill may use quick, balanced or deep mode depending on user intent.
