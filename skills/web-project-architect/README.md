# web-project-architect

`web-project-architect` is the first skill in the Claude Web Skills Kit.

It helps Claude plan professional website projects before moving into design, code, SEO, security, testing or client delivery.

## Purpose

This skill is used when a user wants to:

- create a website
- plan a website
- audit a website
- sell a website to a client
- prepare a landing page
- structure a web project
- identify missing data
- define delivery requirements

## Main value

It prevents Claude from jumping directly into code without understanding:

- business context
- audience
- conversion goal
- website architecture
- risks
- legal placeholders
- SEO requirements
- security requirements
- testing requirements
- missing information

## Default mode

Balanced.
