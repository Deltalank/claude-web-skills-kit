# token-budget-controller

`token-budget-controller` controls context size and output length for large website workflows.

## Purpose

This skill is used when a user wants to:

- reduce token usage
- avoid repeated context
- split large work into phases
- optimize prompts
- choose which files to inspect first
- avoid unnecessary full rewrites
- keep Claude focused on the next useful step
- manage long website projects efficiently

## Main value

It helps Claude keep the right context, remove repetition, preserve safety and choose the smallest useful next action.

## Default mode

Balanced.
