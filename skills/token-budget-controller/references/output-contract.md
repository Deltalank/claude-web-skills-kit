# Token Budget Output Contract

Default output format:

```md
# Token Budget Plan

## 1. Current objective

## 2. Recommended mode

## 3. Essential context

## 4. Useful but optional

## 5. Repeated / compressible

## 6. Out of scope now

## 7. File or task priority

## 8. Output size limit

## 9. Stop conditions

## 10. Next action
```

The goal is not only to be shorter. The goal is to keep useful context and remove waste.
