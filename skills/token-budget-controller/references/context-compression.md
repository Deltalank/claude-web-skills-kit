# Context Compression

Compress context by preserving what matters and removing repetition.

## Preserve

- decisions
- constraints
- file names and paths
- user preferences
- safety rules
- unresolved questions
- current objective
- next action

## Remove or summarize

- repeated explanations
- obsolete attempts
- decorative wording
- long discussions that have already produced a decision
- unrelated background

## Rule

Do not compress away safety constraints, missing data or reasons behind important decisions.
