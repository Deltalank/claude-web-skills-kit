# Bad vs Good Token Output

## Bad output

```text
I will audit everything at once and rewrite all files.
```

Why this is bad:

- no scope
- no priority
- high context cost
- high risk of unnecessary changes
- no stop conditions

## Good output

```text
Recommended mode: staged

Essential now:
- README
- index.html
- main JavaScript
- main CSS

Deferred:
- images
- legal pages
- full SEO audit

Next action:
Review the homepage and main contact path first, then expand only if needed.
```

Why this is good:

- prioritizes the next useful step
- avoids unnecessary context
- keeps the project safe and focused
