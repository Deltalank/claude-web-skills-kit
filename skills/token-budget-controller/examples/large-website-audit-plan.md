# Large Website Audit Plan Example

## User request

```text
Tengo una web con muchos archivos. Quiero revisarla sin malgastar contexto.
```

## Expected behavior

The skill should:

- identify the current objective
- choose a mode
- prioritize files
- defer optional files
- preserve safety rules
- propose a staged plan
- avoid reading everything immediately

## Expected output outline

- Current objective
- Recommended mode
- Essential context
- Useful but optional
- Repeated / compressible
- Out of scope now
- File priority
- Output size limit
- Stop conditions
- Next action
