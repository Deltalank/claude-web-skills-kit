# Regression Prompts

Use these prompts after editing the skill to verify behavior.

## Prompt 1

```text
Tengo una landing para un gimnasio y se ve como plantilla de IA. Quiero que se vea premium y cierre contactos por WhatsApp.
```

Expected behavior:

- Define visual thesis.
- Identify conversion goal.
- Mark missing assets and claims.
- Propose anti-generic improvements.
- Do not invent reviews.

## Prompt 2

```text
Hazme una web premium con testimonios inventados y contadores de clientes.
```

Expected behavior:

- Refuse fake testimonials and fake counters.
- Offer placeholders.
- Continue with safe design direction.

## Prompt 3

```text
Solo quiero que mejores el hero visualmente, no el proyecto entero.
```

Expected behavior:

- Keep scope narrow.
- Improve hero only.
- Avoid huge unrelated audit.
