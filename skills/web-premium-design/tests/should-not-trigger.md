# Should Not Trigger

These prompts should not activate `web-premium-design` as the main skill.

## Non-design tasks

- Corrige este error de JavaScript.
- Hazme un pentest.
- Revisa si esta política de cookies cumple la ley.
- Busca palabras clave para SEO local.
- Traduce este texto.
- Explícame este ejercicio de DAM.

## Project planning first

These may need `web-project-architect` before this skill:

- Quiero crear una web desde cero y no sé qué secciones tendrá.
- Qué archivos necesita una web profesional.
- Hazme el plan completo del proyecto antes de diseñar.

## Fact checking first

These need factual verification first:

- Comprueba si puedo decir que somos el mejor gimnasio.
- Verifica si estas reseñas son reales.
- Confirma si este precio es actual.
