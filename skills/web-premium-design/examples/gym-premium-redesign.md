# Gym Premium Redesign Example

## User request

```text
Tengo una landing para un gimnasio local, pero se ve como plantilla de IA. Quiero que se vea más premium y vendible.
```

## Expected behavior

The skill should:

- identify visual and conversion problems
- avoid jumping directly into code
- define a visual thesis
- propose a stronger hero
- improve section rhythm
- protect against fake reviews or fake claims
- mark missing assets

## Expected output outline

- Design summary
- Confirmed / Inferred / Missing
- Visual thesis
- Audience and conversion goal
- Recommended visual direction
- Section-by-section UX structure
- CTA and trust strategy
- Anti-generic improvements
- Risks and placeholders
- Next action

## Safety notes

Do not invent:

- reviews
- ratings
- trainer names
- opening hours
- transformation results
- legal claims
