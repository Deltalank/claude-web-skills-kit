# Anti-Generic Checklist

Use this checklist to detect AI-looking web design.

## Red flags

- Generic hero headline with no specific offer.
- Meaningless gradient background.
- Too many repeated cards.
- Random icons with inconsistent style.
- Fake statistics.
- Fake testimonials.
- Fake review ratings.
- Stock images that do not match the business.
- Weak mobile hierarchy.
- Multiple CTAs competing at once.
- Sections with no clear purpose.
- Overused SaaS layout for a local business.
- Decorative animation that hurts clarity.

## Better alternatives

- One clear visual thesis.
- Real local proof or explicit placeholders.
- One primary CTA.
- Section rhythm based on user decision-making.
- Mobile-first layout.
- Business-specific copy.
- Consistent typography and spacing.
- Controlled visual risk.
