# web-premium-design

`web-premium-design` helps Claude create distinctive, intentional and conversion-focused visual direction for websites and landing pages.

## Purpose

This skill is used when a user wants to:

- create a premium web design
- redesign a website
- improve a landing page
- make a web project look less generic
- define visual direction
- improve UX structure
- improve conversion through design
- prepare a client-facing web demo

## Main value

It prevents Claude from producing generic AI-looking websites by requiring:

- a visual thesis
- mobile-first structure
- clear CTA strategy
- intentional typography, color and spacing
- anti-generic design checks
- trust and conversion thinking
- placeholders for missing data
- no fake testimonials or claims

## Default mode

Balanced.
