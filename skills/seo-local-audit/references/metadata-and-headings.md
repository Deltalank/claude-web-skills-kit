# Metadata and Headings

## Title tag

A local-business title should usually communicate:

- primary service
- business name when useful
- target location when relevant

Avoid stuffing repeated locations or services.

## Meta description

A useful meta description should:

- describe the service clearly
- mention location when relevant
- include a natural contact or value cue
- avoid fake claims
- avoid guaranteed rankings or results

## H1

The page should normally have one clear H1 that describes the main page purpose.

## H2/H3 structure

Headings should help users and search engines understand:

- services
- location
- who the service is for
- trust signals
- contact path
- frequently asked questions

Do not use headings only for styling.
