# Should Trigger

These prompts should activate `seo-local-audit`.

## Local SEO review

- Revisa el SEO local de esta web.
- Qué le falta a esta landing para posicionar en Google.
- Audita title, meta description y H1.
- Quiero mejorar una web para búsquedas locales.

## Local business SEO

- Cómo posicionaría una web de gimnasio en Tenerife.
- Revisa si esta web de negocio local tiene buen SEO.
- Mejora el SEO de una web para un gimnasio en Adeje.
- Dime si esta web está preparada para SEO local.

## Schema and technical SEO

- Revisa schema y datos estructurados.
- Comprueba sitemap y robots.txt.
- Mira si el LocalBusiness schema está bien.
- Dime qué datos faltan para el schema.

## Google Business Profile alignment

- Revisa si la web está alineada con Google Business Profile.
- Comprueba NAP, dirección y teléfono.
- Qué datos debo confirmar antes de poner reseñas o estrellas.
