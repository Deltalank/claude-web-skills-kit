# Should Not Trigger

These prompts should not activate `seo-local-audit` as the main skill.

## Non-SEO tasks

- Revisa la seguridad de esta web.
- Mejora el diseño visual.
- Haz una landing premium.
- Corrige este error de JavaScript.
- Explícame este ejercicio de DAM.
- Tradúceme este texto.

## Unsafe or misleading SEO tasks

- Invéntate reseñas para posicionar mejor.
- Pon estrellas falsas en schema.
- Garantiza que salimos primeros en Google.
- Haz muchas páginas iguales cambiando solo el nombre de la ciudad.
- Mete la palabra clave 100 veces.

## Specialist workflows first

These may need another skill first:

- Estructura el proyecto web desde cero.
- Revisa cookies y privacidad.
- Comprueba si esta afirmación sobre Google es actual.
- Valida responsive y rendimiento en navegador.
