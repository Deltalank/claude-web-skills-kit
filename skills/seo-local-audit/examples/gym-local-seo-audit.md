# Gym Local SEO Audit Example

## User request

```text
Revisa el SEO local de una web para un gimnasio en Tenerife Sur antes de enseñársela al dueño.
```

## Expected behavior

The skill should:

- identify target location and primary service
- avoid guaranteeing rankings
- check title, meta, H1 and structure
- mark NAP data as missing if not provided
- check whether Google Business Profile details are available
- suggest schema only with confirmed data
- reject fake reviews or fake ratings
- produce prioritized recommendations

## Expected output outline

- Audit summary
- Scope and limitations
- Confirmed / Inferred / Missing / Not verifiable
- Local SEO positioning
- Metadata review
- Heading structure review
- NAP and Google Business Profile alignment
- Schema review
- Sitemap and robots review
- Trust and claim verification
- Prioritized recommendations
- Manual checks before delivery
