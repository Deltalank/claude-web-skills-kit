# seo-local-audit

`seo-local-audit` reviews local-business websites for local SEO, metadata, structure, schema, Google Business Profile alignment and location-based conversion risks.

## Purpose

This skill is used when a user wants to:

- review local SEO
- improve a local business website
- check metadata and headings
- review schema or structured data
- check sitemap and robots
- align website content with Google Business Profile
- identify local SEO gaps before client delivery
- avoid fake reviews, fake ratings and fake ranking claims

## Main value

It helps Claude provide structured local SEO guidance without guaranteeing rankings or inventing business data.
