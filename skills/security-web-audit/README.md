# security-web-audit

`security-web-audit` reviews static websites and simple web projects for security, privacy and configuration risks before publishing or client delivery.

## Purpose

This skill is used when a user wants to:

- review website security
- audit a web project before delivery
- check `.htaccess`
- review CSP and security headers
- check cookies, analytics and tracking
- check external scripts and CDNs
- review forms and personal data flows
- detect exposed secrets or risky files
- identify what must be verified before publishing

## Main value

It prevents Claude from saying a website is "safe" without scope, limitations, severity, verification steps and privacy review.
