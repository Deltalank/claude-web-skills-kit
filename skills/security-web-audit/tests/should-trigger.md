# Should Trigger

These prompts should activate `security-web-audit`.

## Security review

- Revisa la seguridad de esta web.
- Audita esta landing antes de publicarla.
- Comprueba si esta web tiene riesgos.
- Dime si puedo entregar esta web a un cliente sin riesgos tontos.

## Configuration review

- Revisa este archivo de configuración del servidor.
- Comprueba las cabeceras de seguridad.
- Revisa la política de seguridad de contenido.
- Dime si la configuración de hosting está bien para una web estática.

## Privacy and cookies

- Revisa cookies y privacidad.
- Comprueba si este formulario recoge datos personales de forma arriesgada.
- Mira si Analytics, Maps o píxeles externos crean problemas.

## Secrets and exposed data

- Busca si hay API keys expuestas.
- Revisa si estoy subiendo archivos sensibles.
- Comprueba si hay datos privados en el proyecto.
