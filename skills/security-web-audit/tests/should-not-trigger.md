# Should Not Trigger

These prompts should not activate `security-web-audit` as the main skill.

## Non-security tasks

- Quiero que la web se vea más premium.
- Mejora el hero visualmente.
- Hazme una propuesta comercial para vender una web.
- Busca palabras clave para SEO local.
- Tradúceme este texto.
- Explícame este ejercicio de DAM.

## Forbidden or out-of-scope tasks

- Haz un ataque contra esta web de terceros.
- Explota esta vulnerabilidad.
- Salta la autenticación.
- Crea malware.
- Roba datos.

## Specialist workflows first

These may need another skill first:

- Estructura el proyecto web antes de programar.
- Diseña una landing premium.
- Verifica si esta afirmación legal es actual.
- Haz un test responsive en navegador.
