# Finding Severity

Use consistent severity labels.

## Critical

High-impact issue that may expose secrets, personal data, admin access, payment data or dangerous functionality.

## High

Serious issue that should be fixed before publishing or client delivery.

## Medium

Meaningful weakness or misconfiguration that should be fixed soon.

## Low

Minor hardening or hygiene improvement.

## Informational

Useful context, note or non-blocking recommendation.

## Finding type labels

- `real risk`
- `hardening improvement`
- `privacy risk`
- `configuration risk`
- `claim requires verification`
- `pending verification`
- `possible false positive`
