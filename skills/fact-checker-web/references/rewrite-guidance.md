# Rewrite Guidance

Use safer wording when a claim is too strong or unsupported.

## Safer patterns

- "designed to help"
- "focused on"
- "available for"
- "located in [LOCATION_TO_CONFIRM]"
- "contact for current prices"
- "opening hours to confirm"
- "verify before publishing"
- "demo text — replace before publishing"

## Rule

Keep the persuasive intent when possible, but remove unsupported proof.
