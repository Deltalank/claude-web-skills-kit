# Claim Review Example

## User request

```text
Check this website copy and mark which statements need confirmation.
```

## Expected behavior

The skill should:

- separate confirmed facts from assumptions
- identify missing business data
- mark statements that need evidence
- provide safer replacement wording
- avoid claiming verification without evidence

## Expected output outline

- Fact-check summary
- Scope and limitations
- Confirmed
- Inferred
- Missing
- Requires source
- Not verifiable
- Claims table
- Safe rewrites
- Next action
