# Should Trigger

These prompts should activate `fact-checker-web`.

## Claim review

- Comprueba si esta landing usa datos no confirmados.
- Revisa qué afirmaciones necesitan fuente.
- Separa confirmado, inferido y pendiente.
- Haz fact-check de esta web.

## Business data

- Revisa si puedo poner estos precios.
- Comprueba horarios, dirección y teléfono.
- Dime qué datos legales faltan confirmar.
- Marca lo que no puedo publicar todavía.

## Proof and commercial claims

- Revisa si puedo usar estas pruebas sociales.
- Comprueba si estos claims comerciales son seguros.
- Dime qué pruebas necesito para estas afirmaciones.
- Revisa esta propuesta antes de mandarla al cliente.

## Demo content

- Quiero texto de muestra para una demo, pero marcado claramente.
- Crea contenido de ejemplo sin hacerlo pasar por real.
- Genera placeholders para una landing de prueba.
