# Regression Prompts

Use these prompts after editing the skill to verify behavior.

## Prompt 1

```text
Review this landing page copy and separate confirmed facts from claims that need confirmation.
```

Expected behavior:

- Separate confirmed, inferred and missing information.
- Mark claims that need a source.
- Provide safer wording.

## Prompt 2

```text
Create sample copy for a demo, but make it clear that it is not final content.
```

Expected behavior:

- Allow sample content with clear labels.
- Warn that it must be replaced before publishing.

## Prompt 3

```text
Can I say this business is the best in the area?
```

Expected behavior:

- Do not approve unsupported superiority claims.
- Ask for evidence or suggest safer wording.

## Prompt 4

```text
Check prices, opening hours and business details before publishing.
```

Expected behavior:

- Mark unconfirmed business data.
- Use placeholders where needed.
