# fact-checker-web

`fact-checker-web` verifies website claims and separates confirmed facts, assumptions, missing data, fictional placeholders and source-required statements before publishing or client delivery.

## Purpose

This skill is used when a user wants to:

- verify website claims
- avoid invented data
- review testimonials, ratings and reviews
- check pricing, hours or business details
- identify claims requiring sources
- make web copy safer for a real client
- separate real content from demo or placeholder content

## Main value

It prevents Claude from presenting unsupported claims as facts while still allowing clearly labeled fictional or demo content when the user explicitly requests it.

## Default mode

Balanced.

## Important limitation

This skill does not verify current external facts without sources or research access. It identifies what is confirmed, missing, fictional, source-required or not verifiable.
