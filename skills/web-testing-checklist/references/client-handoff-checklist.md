# Client Handoff Checklist

Before showing a website to a client, confirm or mark pending:

- Main pages are present.
- Main contact path works.
- Mobile layout is usable.
- Navigation works.
- Legal links are visible.
- Images load correctly.
- No obvious broken assets.
- Contact details are confirmed.
- Placeholder content is removed or clearly marked.
- SEO-visible basics are present.
- Security and privacy review has been considered.
- Remaining manual checks are listed.

## Rule

Do not present a website as finished if placeholders, unverified claims or broken contact paths remain.
