# Testing Baseline

Use this baseline before publishing or client delivery.

## Core checks

- Main call to action works or is marked as needing manual review.
- Navigation links work or are marked as needing manual review.
- Contact paths are clear.
- Mobile layout is usable.
- There is no obvious horizontal overflow.
- Legal links are present or marked as missing.
- Images load and scale correctly.
- Forms have expected success and error behavior or are marked as pending.
- Browser console is checked or marked as pending.
- SEO-visible basics are reviewed.
- Accessibility basics are reviewed.
- Performance basics are reviewed.

## Delivery rule

Do not say a site is ready unless the review scope and remaining manual checks are visible.
