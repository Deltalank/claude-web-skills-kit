# Responsive Matrix

Check at least four viewport groups:

- small mobile
- large mobile
- tablet
- desktop

## For each viewport, review

- hero readability
- main CTA visibility
- navigation usability
- no horizontal overflow
- images scale correctly
- text remains readable
- cards and sections do not overlap
- footer and legal links remain usable
- sticky elements do not hide content

## Rule

If mobile contact flow is broken, mark the issue as a blocker or high risk depending on severity.
