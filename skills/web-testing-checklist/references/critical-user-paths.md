# Critical User Paths

The most important checks are the paths that real users take.

## Local business default path

1. User lands on homepage.
2. User understands the business, service and location.
3. User finds the primary contact option.
4. User taps or submits the contact action.
5. User reaches a working next step.

## Common critical paths

- Homepage to WhatsApp.
- Homepage to phone call.
- Homepage to contact form.
- Homepage to map or location.
- Navigation to services.
- Navigation to legal pages.
- Mobile menu to primary CTA.

## Rule

If the main contact path is broken, client delivery should stop until fixed or clearly marked as pending.
