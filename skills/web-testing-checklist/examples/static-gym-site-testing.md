# Static Gym Site Testing Example

## User request

```text
Comprueba si esta web está lista para enseñársela al dueño del gimnasio.
```

## Expected behavior

The skill should:

- identify the main contact path
- check or request pages/files
- list what was checked
- list what needs manual browser or device review
- validate responsive concerns
- check legal and trust links
- check SEO-visible basics
- avoid saying ready without limitations

## Expected output outline

- Testing summary
- Scope and limitations
- Checked / Needs manual review / Missing / Not verifiable
- Critical user paths
- Links and navigation
- Contact and CTA checks
- Responsive checklist
- Legal and trust checks
- Findings by severity
- Final delivery checklist
