# Contact Flow Example

## User request

```text
Revisa si el botón de WhatsApp, teléfono y formulario están bien antes de entregar la web.
```

## Expected behavior

The skill should:

- identify each contact method
- check visible link format when files are provided
- mark device behavior as needing manual review
- check success and error states for forms when possible
- identify blockers in the main contact path

## Notes

Contact flow is usually one of the most important delivery checks for a local business website.
