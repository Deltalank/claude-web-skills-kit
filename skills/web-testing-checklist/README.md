# web-testing-checklist

`web-testing-checklist` validates websites before publishing, client review or final delivery.

## Purpose

This skill is used when a user wants to:

- test a website before delivery
- check if a website is ready to publish
- validate links, buttons and CTAs
- check responsive behavior
- review forms and contact flows
- check WhatsApp, phone and email links
- create a final client handoff checklist
- identify blockers before publishing

## Main value

It prevents Claude from saying a website is ready without checking scope, critical user paths, responsive behavior, contact flows, legal links, accessibility basics, performance basics and manual verification gaps.

## Default mode

Balanced.

## Important limitation

This skill does not replace real browser/device testing. It creates a structured QA workflow and marks what must be manually verified.
