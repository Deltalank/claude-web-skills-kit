# Support

This repository is an experimental professional skills kit.

## How to ask for help

Open a GitHub issue with:

- the skill name
- what you expected
- what happened
- the prompt used
- the Claude surface used, for example Claude Web or Claude Code
- whether the issue is about activation, output quality, safety, documentation or packaging

## Do not share

Do not include secrets, real client private data, private screenshots, credentials or unredacted personal data.

## Known limitations

- Skills do not guarantee factual correctness.
- Skills do not replace legal review.
- Skills do not replace security testing.
- Skills do not guarantee SEO ranking or business results.
- Claude Web and Claude Code may handle skills differently.
